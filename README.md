# PingDoctor (پینگ‌دکتر) ⚡🩺

یک ابزار سریع، سبک و هوشمند اندروید برای تست زنده اتصال و تفکیک خودکار کانفیگ‌های سالم از سوخته.

## ویژگی‌های کلیدی
- **پارسر فوق سریع کلیپ‌بورد:** شناسایی خودکار لینک‌های `vless://`، `vmess://`، `trojan://` و `ss://` از متن‌های طولانی و کانال‌های تلگرام.
- **تست واقعی TCP و TLS Handshake:** بررسی برقراری ارتباط با پورت و معتبر بودن SNI برای تشخیص فیلترینگ با کمترین مصرف باتری و اینترنت.
- **تست هم‌روند و موازی:** بررسی ده‌ها کانفیگ به‌صورت همزمان در چند ثانیه با Coroutines.
- **دکمه پاکسازی سوخته‌ها (Purge Dead):** حذف تمام کانفیگ‌های تایم‌اوت، قطع و مسدود شده با یک لمس.
- **کپی کانفیگ‌های سالم (Copy Alive):** کپی یکجای کانفیگ‌های سبز برای پیست مستقیم در v2rayNG و Nekobox.
- **رابط کاربری مدرن Material 3 و دوزبانه:** پشتیبانی کامل از زبان فارسی و انگلیسی همراه با فونت وزیرمتن و تم تاریک دارک‌اسلیت.
